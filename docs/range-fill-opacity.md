# Диапазонная непрозрачность сплошной заливки текста

База: актуальный `origin/main`, `df2a5ef409fdfce725ddd3d22b7b4f1f05ebb2b9`
(merged PR #122). Реализация использует его общий Canvas painter и overlay.

## Модель и отрисовка

- `src/model/rich-text.mjs`: sparse `textRuns.style.fillOpacity` принимает только
  конечные числа 0–100. Явные 0 и 100 сохраняются даже при совпадении со слоем;
  `null` удаляет override. Невалидный patch не заменяет существующий override.
  Используются прежние normalize/apply/replace/history и UTF-16 boundaries.
- `src/render/rich-text-layout.mjs`: приоритет `run → element → 100`. Alpha
  разделяет paint fragments, исключена из geometry key и не меняет logical
  advances, переносы, baseline или auto-fit. Используется существующее после
  PR #122 контекстное позиционирование на границах paint. Разные alpha могут
  разделять `fi`, как разные stroke-стили; соседние цветные группы не сдвигаются.
  Прямоугольники U/S несут alpha своего исходного диапазона.
- `src/render/text-stroke.mjs`: для solid перед каждым `fillText`/`fillRect`
  входная `globalAlpha` умножается на эффективную alpha ровно один раз;
  `save`/`restore` возвращают контекст. Stroke-pass по-прежнему использует только
  слойную `strokeOpacity`; `element.opacity` поступает от вызывающего painter.
  Сохраняется порядок fill/U/S → stroke.
- Для gradient/image/none диапазонная alpha не разделяет glyph calls и не
  меняет alpha масок. Ключ layout-cache различает solid и остальные заливки.

## WYSIWYG и цветовое окно

- `src/editor/wysiwyg-session.mjs`: тот же overlay включается при stroke или
  эффективной alpha != 100, в том числе при слойной alpha без runs и без stroke.
  DOM хранит Selection/каретку; при overlay не рисует ни glyph ink, ни U/S-фон.
  Eligibility теперь допускает слойную fillOpacity != 100. Геометрия overlay,
  DPR, zoom, scroll и resize используют прежнюю механику PR #122.
- `src/editor.js`: alpha-контролы существующего окна при непустом WYSIWYG
  Selection вызывают `applyRangeStyle({fillOpacity})` через
  `styleInlineSelection`. При одной каретке выводится просьба выделить текст.
  Вне редактирования остаётся изменение слоя; несколько выбранных слоёв
  обрабатываются даже при пустом `active()`.
- Mixed показывает пустое число с placeholder `Mixed` и `aria-valuetext` у
  слайдера. Пустой ввод не становится нулём. Стрелки и существующие степперы
  начинают с эффективной alpha первого символа. Фокусируемый числовой ввод не
  перезаписывается при каждом input, поэтому первый введённый символ сохраняется.
- Preview, направленность Selection и Undo/Redo принадлежат существующей
  WYSIWYG-истории. Последовательные input до change образуют одно действие.
  Изменение alpha не вызывает fit.

## Проверки и доказательства

Unit-тесты дополнены в `tests/text-stroke.test.mjs`; ожидание эффективного стиля
обновлено в `tests/rich-text-layout.test.mjs`. E2E дополнены в
`tests/range-stroke.spec.js`, с прежней конфигурацией двух браузеров.

Покрыты строгая валидация, endpoints/overrides/null, пересечения, UTF-16,
вставка/удаление, Undo/Redo, JSON/backup и повторное открытие IndexedDB v3.
UI проверяет обратное выделение, Mixed, пустой ввод и стрелки, живой preview,
контролы alpha 0/50/100, несколько слоёв, импорт/экспорт и повторное открытие.
Проверяются LF/soft wrap, AV, partial/whole fi с независимым native Canvas oracle,
смешанные шрифты/размеры/leading/spacing, U/S и auto-fit ON/OFF.

Пиксельные допуски PR #122 сохранены: Canvas/скачанный PNG ≤1 на канал,
overlay/PNG и screenshot живого/закрытого редактора ≤2 на канал для каждого
пикселя. Нет подгонки сдвигов, ресэмплинга для улучшения совпадения, бюджета
больших отклонений или обновления исторических PNG. Экранный ROI исключает
рамку/resize handles; backing-raster и экспорт проверяются целиком.

Сценарий 0% использует реальный нижний raster-слой с контрастным клетчатым
изображением: считает внутренние пиксели букв, ранее покрытые заливкой,
которые теперь равны пикселям изображения. Отдельно проверяются сохранённые
пиксели непрозрачного контура по независимому native Canvas oracle
и неизменность соседнего слова.

Численные результаты и выбранные PNG находятся в
[`docs/evidence/range-fill-opacity/`](evidence/range-fill-opacity/).

## Ограничения

Объём: обычный горизонтальный текст со сплошной заливкой. Диапазонные
strokeStyle/strokeOpacity не добавлены. Gradient/image/none, path, vertical,
arc, justify и прочие исключённые eligibility-режимы не расширены. Общая
opacity слоя != 100 по-прежнему не допускается в WYSIWYG eligibility.
Схема IndexedDB v3, исторические файлы и PNG-эталоны не менялись.

Полный Playwright оставлен GitHub Actions. Завершение Actions в сессии не
ожидалось. Merge и production deploy не выполняются.

| Адресные model/layout/painter/history unit | 57/57 |

| `npm run test:source` | 17/17 |
| Chromium + Firefox, уникальные адресные E2E | 50 подтверждено |
| `npm run build`, `npm run build:verify` | PASS |
| `git diff --check` | PASS |

E2E выполнялись основным адресным прогоном (46: 40 PASS, 6 FAIL новых
пиксельных фикстур), затем точечными перепроверками. Четыре случая LF/U/S
захватывали боковую рамку выделения; экранный ROI ограничен внутренней областью
текста, как в retina-проверке PR #122. Для нижнего изображения мелкие буквы
были почти полностью покрыты контуром; финальная фикстура — `HH NN`, 64 px,
непрозрачный контур 1 px. Его непрозрачность проверяется независимым native
Canvas oracle, соседнее слово — точным сравнением с исходным экспортом.
После изменения фикстур прогон 10 случаев подтвердил 8 сценариев (включая
четыре новых `fi` oracle); финальная перепроверка нижнего изображения прошла
2/2. Промежуточная проверка нижнего изображения также выявила различие Firefox
в растрировании whole/split glyph calls; её заменило сравнение с независимым
oracle правильных split calls. Попиксельные допуски не менялись.
[`pixels.json`](evidence/range-fill-opacity/pixels.json) содержит последний
результат каждого из 50 уникальных сценариев и измерения.

| Пиксельное сравнение alpha-сценариев | Максимальная разница канала |
| --- | --- |
| Canvas / скачанный PNG | 0 |
| Живой overlay / PNG | 2 |
| Screenshot живого / закрытого редактора | 2 |

Внутренние пиксели букв, полностью открывшие нижнее изображение: Chromium 422,
Firefox 1492; цветных пикселей сохранённой обводки: 1882 / 460. У соседнего
слова — 0 изменённых пикселей в обоих браузерах. Для сценария нижнего изображения
независимый oracle совпал с экспортом точно (0 на канал в обоих браузерах).
