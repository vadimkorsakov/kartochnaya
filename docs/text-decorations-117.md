# Диапазонные U/S — issue #117

## Модель и управление

Используются существующие boolean `underline` / `strikethrough` в `textRuns`.
Приоритет для каждого свойства: явный run (включая `false`) → поле слоя →
legacy `mobileUnderline` / `mobileStrike` → `false`. Загрузка не удаляет legacy
поля. Нормализация сравнивает run с тем же эффективным наследованием, поэтому
отключение части legacy-оформления не пропадает при редактировании.

Desktop и мобильные кнопки используют существующие `styleInlineSelection`,
`applyTextStyle` и историю сессии. Mixed вычисляется по всем эффективным
сегментам, включая пробелы и разрывы строк; Mixed → ON. Без выделения команда
оформляет весь слой и снимает переопределения только выбранного свойства,
сохраняя остальные стили. Поддерживается выбор нескольких текстовых слоёв.
Отдельного состояния оформления будущего ввода нет.

## Отрисовка и геометрия

`rich-text-layout.mjs` возвращает `row.decorations` в координатах документа.
`text-decorations.mjs` задаёт прямоугольники линий: толщина `max(1, size/19)`,
центр подчёркивания `baseline + size*.1`, зачёркивания `baseline - size*.31`.
Это прежние слойные коэффициенты с размером и цветом конкретного диапазона.
Линия использует эффективный `textColor`.

U/S исключены из geometry key **и из ключа разбиения глифов для рисования**.
Текст с одним шрифтом/цветом продолжает рисоваться целиком при добавлении U/S:
границы декораций не разрывают кернинг или лигатуры. Границы линий рассчитываются
по исходным интервалам и Canvas advances; символы LF не рисуются, soft-wrap не
добавляет символов. Комбинируемые символы и ZWJ используют прежнее правило
принадлежности всей графемы её первому символу. Декорации не запускают auto-fit.

Canvas и PNG рисуют эти прямоугольники через `fillRect`. DOM WYSIWYG использует
те же координаты в background-градиентах уже существующих строк. Дополнительных
элементов, текстовых узлов или caret stops нет; `textContent`, UTF-16 Selection
и проверка подтверждённого HTML остаются прежними.

## Ограничения

Полная диапазонная отрисовка относится к обычному горизонтальному layout.
Vertical/path/boundary, дуга и justify сохраняют специальные старые painters и
их слойное поведение; их движок и eligibility WYSIWYG не расширены. Эффекты,
маски, повороты и прочие прежние причины fallback остаются прежними.
Мобильное редактирование остаётся textarea: диапазон сохраняется в модели,
его оформление видно на Canvas после закрытия поля и в PNG. Desktop WYSIWYG
показывает линии непосредственно во время редактирования.

`underlineDetails` / `strikethroughDetails` сохраняются, но не настраивают линии.
Нет изменений IndexedDB v3, формата документов, интерлиньяжа или обводки.
Одинаковая геометрия линий не означает побитового равенства сглаживания DOM и
Canvas при произвольном масштабе экрана.

## Проверки

`tests/text-decorations.test.mjs` проверяет приоритет, явное false, UTF-16,
графемы, пересечения U/S, нормализацию, историю, JSON/backup/IndexedDB v3,
неизменность глифов, кернинга, метрик и переносов.

`tests/text-decorations.spec.js` проверяет реальные mouse/keyboard Selection,
обратное выделение, Mixed, Space на кнопке, auto-fit ON/OFF, историю внутри и
после сессии, Escape, экспорт JSON, запись IndexedDB и повторное открытие,
мобильные legacy-документы и выбор нескольких слоёв. Пиксели настоящих DOM
screenshots и скачанного PNG проверяются отдельно от наблюдения Canvas calls.
Координаты DOM/Canvas сравниваются с допуском 0,001 px, границы одного слова —
с реальным DOM Range; соседние невыделенные символы не получают линию.
PNG-эталоны не обновляются. Firefox запускается через существующую
`playwright.selection.config.js`, включая Netlify bundle.
