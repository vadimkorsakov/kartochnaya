## Контракты и исходное воспроизведение

`mobileV36Nudge` немедленно меняет координаты незаблокированных выбранных слоёв, рисует и вызывает `saveSoon`. Первый повтор начинается через 360 + 70 ms, затем каждые 70 ms. Прежний `mobileV36EndNudge` очищал таймер и при started вызывал commit. `mobileV36Commit` вызывает commit и refreshLayers; commit сравнивает snapshot с текущей историей, но даже при равенстве вызывает saveSoon. Сохранение дополнительно дедуплицируется по сериализованной модели и подтверждается transaction complete.

`mobileV36UpdatePlane` через `mobileV36ApplyColor(..., false)` сразу меняет fill/textColor, stop градиента или цвет эффекта, перерисовывает preview и планирует сохранение. Pointerup фиксировал результат. Pointercancel без проверки типа/ID вызывал и EndNudge, и Commit. Pointerdown второй стрелки завершал первую; pointerup выбирал действие по DOM target, а не владельцу. Close удалял DOM панели без завершения её preview/повтора.

`copyLayers` сохраняет выделенный граф и идентичность исходного документа/слайда в памяти, не меняет документ и не вызывает commit. `pasteLayers` использует существующий remap/append, выбирает новые ID и делает один commit. `duplicateElement` отдельно создаёт копии незаблокированных слоёв с собственным смещением и суффиксом. Мобильный обработчик copy последовательно вызывал обе функции — причина F-06B.

До изменения production-кода добавлены Playwright-воспроизведения и сохранены коммитом `21bc615`. Затем уточнённый fixture воспроизведения повторно запущен в detached worktree на **неизменённой базе**: **14 failed, 4 passed**. [Машиночитаемый результат](mobile-interactions-f06-baseline.json).

Два вызова commit не равны двум записям истории или IndexedDB: существующее сравнение snapshots и дедупликация убирают часть повторов. У обычного plane cancel **не воспроизведены** откат цвета или двойная запись истории. Эти дефекты базе не приписываются.

## Ограниченное исправление

Только мобильная подсистема `src/editor.js`:

- У nudge/plane один владелец: type, pointerId, target, documentId и исходная сериализация elements/groups. Второй pointerdown не крадёт операцию; последующий click стрелки не завершает чужое удержание.
- Move принимается только для plane и совпавшего ID. Window capture слушает up/cancel/lostpointercapture и завершает только совпавшего владельца (для lostpointercapture совпадает и target); DOM target не определяет тип операции. Это работает и при недоступном capture / отпускании вне панели.
- Владение снимается **до** releasePointerCapture и commit. Таймаут и интервал очищаются. Повторный cancel, последующий up и lostcapture становятся пустыми действиями.
- Close, смена инструмента, render с заменой DOM и явная команда панели завершают её preview до смены контекста. Существующий EndNudge остаётся узким entry point для своего типа.
- Commit вызывается только при реальном изменении elements/groups в том же документе. Посторонние события не фиксируют незавершённые inputs; locked/no-op не добавляют действий.
- Мобильная «Копировать» вызывает только copyLayers. Для нескольких выбранных слоёв «Ещё» показывает batch-действия. Контролы, требующие active(), остаются только при единственном слое.

Отдельный чистый модуль не выделялся: состояние небольшое и связано с capture, DOM и таймерами; его реальный контракт проверяется browser-тестами. Нет unit-тестов, повторяющих реализацию. Существующие unit для графа и сохранений используются как регрессии.

## Семантика отмены

**Сохранять последнее реально применённое значение** для nudge, solid/text, gradient и effect plane. Это сохраняет прежний контракт plane cancel и учитывает, что preview уже изменил модель и мог попасть в IndexedDB. Отмена прекращает поток указателя, фиксируя один настоящий результат; отдельного действия «отмена» нет. Если данные не изменились, финального commit нет. Закрытие панели использует ту же политику.

Двухпальцевый router остаётся прежним: он работает в stageScroller, принимает trusted touch, восстанавливает предварительное canvas-перемещение, потребляет stage-указатели и изменяет только viewport. Указатели панели не являются stage-жестом; универсальный перехват второго пальца для любой панели не добавлялся.

## Проверки поведения

27 новых мобильных Playwright-сценариев: viewport 390×844, hasTouch/isMobile, настоящие trusted touch через Chromium CDP, управляемые Pointer Events для чужих ID и отсутствующего capture. Приложение не экспонируется и внутренние функции не вызываются. Проверяются JSON-export, DOM истории/выделения, readonly IndexedDB после reload, реальные координаты и ID, capture, последующие жесты и остановка повторов.

Наблюдение setTimeout(420) различает **планирование сохранения**, а наблюдение docs.put / transaction complete — реальные записи. Для единичных изменений проверена одна запись после завершения; при длительном preview допустимы реальные промежуточные состояния. Перед проверкой paste отдельно дожидаемся сохранения подготовленного документа, чтобы не считать его предыдущий put повторной вставкой.

Проверены single, additive pair и explicit nested group; внутренние sourceId/clipBaseId и parentId/custom группы; fresh IDs и смещение +24; единственный title owner; одно действие paste и ноль действий copy. В другом документе доступные скопированные ссылки переназначаются, отсутствующие внешние ссылки отсоединяются с сохранением fallback — существующая семантика PR #35. Исходный документ не изменяется. Сохранены отдельное Duplicate, Undo/Redo, текстовый редактор и блокировка.

## Границы

Не изменены canvas-graph.mjs, desktop-клавиатура, IndexedDB v3, сериализация ZIP/JSON, облака/OAuth, workspace replacement, рендер/PNG, Web Locks и подтверждения записи, исторические PNG, тесты/таймауты/skip существующих сценариев. Существующий мобильный тест градиентов остаётся без адаптации.

Независимые ограничения: остальные панели свойств всё ещё требуют единственный active layer; данный PR разрешает только необходимую для copy/paste панель «Ещё». Буфер живёт в памяти текущего экземпляра редактора. «Ещё» требует выделение и при вставке в другой документ тестируется с выбранным слоем назначения; отдельный UI вставки на пустом холсте не добавлялся. Проверка Chromium не заменяет ручное испытание аппаратных жестов Android/IME.

Результаты полного локального регресса и GitHub Actions приведены в PR для итогового SHA.
