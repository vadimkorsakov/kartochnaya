# Форматирование выделения в textarea

Горизонтальный текст использует существующие desktop/mobile инструменты шрифта,
начертания, размера, цвета и трекинга. Непустой диапазон textarea передаётся в
`applyTextStyle()`; без выделения сохраняется изменение всего слоя. Нормализация,
пересечения, удаление базовых переопределений и границы UTF-16 остаются в модели.
Вертикальный текст, текст по кривой, boundary, дуга и justify сохраняют свой путь.

`selectionStart`, `selectionEnd`, `selectionDirection` сохраняются до передачи
фокуса инструментам, а также при select/keyup/input/pointerup и blur. Панели могут
получить обычный фокус, включая числовую клавиатуру Android, не завершая сессию.
Форматирование восстанавливает диапазон без принудительного фокуса textarea.
Повторный вход через «Править» возвращает фокус и выделение. Новых элементов UI нет.

Размер выбранных символов переводится из текущих пикселей в опорные единицы:
`requested * textRunsBaseFontSize / fontSize`. Если опорного размера ещё нет,
используется текущий размер слоя; затем вызывается существующий
`retainRichTextSizeBase()`. Ручной размер отключает автоподбор, как поле размера
всего слоя: остальные фрагменты сохраняют и исходные размеры, и текущий масштаб.
Последующее включение автоподбора снова масштабирует все фрагменты пропорционально.
Остальные метрические изменения используют существующий пересчёт раскладки.

Изолированная история `inline-text-history.mjs` хранит снимки слоя и курсора
только в памяти сессии. До первого форматирования браузер управляет обычным undo
ввода, включая сгруппированные операции. После форматирования Ctrl/Cmd+Z,
Ctrl/Cmd+Shift+Z, Ctrl+Y, beforeinput historyUndo/historyRedo и существующие кнопки
истории восстанавливают текст вместе со стилями. Input-preview и финальный change
одного инструмента дают один снимок; новая правка после Undo отсекает Redo.
При завершении снимки передаются в существующую историю документа, без отдельного
повторного коммита закрытия. Сессии без форматирования сохраняют прежнее правило
одного коммита. Desktop Escape восстанавливает весь исходный слой, включая опорный
размер и флаг автоподбора; мобильная «Готово» сохраняет текущую сессию.

Textarea временно показывает базовый стиль. Смешанные стили видны в Canvas после
завершения ввода и в PNG; WYSIWYG остаётся отдельной задачей. CSS имитации смешанных
стилей не добавлены. Схемы JSON/ZIP/IndexedDB и документы без textRuns не меняются.

Браузерные сценарии: `tests/selected-text-formatting.spec.js`, вместе с существующими
`rich-text`, `rich-text-rendering`, `inline-text` и `mobile-inline-text`. Проверки
используют настоящие UI-события, наблюдают вызовы Canvas без подмены рисования,
проверяют пиксели экрана/PNG и повторное открытие из IndexedDB. Мобильный Chromium
эмулирует touch/viewport; аппаратная клавиатура и системные Android handles требуют
проверки на устройстве.
