# КАРТОЧНАЯ v0.45

Автономный графический редактор. `index.html` побайтово совпадает с `kartochnaya_v043_onefile.html`.

## Новые эффекты текста (v0.45)

Через существующий раздел «Эффекты» доступны пять пресетов, хранящихся в стандартном массиве слоя `effects[]`:

- **Подсветка:** цветной мягкий ореол от альфа-контура букв; интенсивность, радиус, цвет.
- **Эхо:** ступенчатая серия копий глифов; направление, расстояние, цвет.
- **Фон:** округлённые подложки под каждую реально отображаемую строку; округлость, распространение, прозрачность, цвет. Для вертикального и текста вдоль границы используется контурное расширение формы букв.
- **Совмещение:** смещённая цветная копия с регулируемой толщиной; толщина, смещение, направление, цвет.
- **Искажение:** два смещённых цвета вдоль указанной оси; направление, смещение, первый и второй цвета.

Новые пресеты используют **общий Canvas2D-композитор слоя**, поэтому не создают отдельные слои и попадают в обычный PNG-экспорт. Изменение текста и геометрии сохраняет эффект. Для новых пресетов действует выбор одного пресета этого набора на объект; остальные существующие эффекты доступны независимо. Четыре альфа-контурных эффекта могут применяться и к фигурам и прозрачным PNG; построчная подложка предназначена для текста.

Мобильная панель использует выбор пресета первым касанием и параметры по повторному нажатию. Цвет можно задать стандартной кнопкой цвета либо через встроенный редактор HEX/HSV.

Рендеринг проверен программно в Chromium (разные параметры, две строки, шрифты, изменение текста, ширины слоя, JSON roundtrip, несколько фигур). Не подтверждена работа на реальном Android/Firefox и IndexedDB после перезапуска.

## Новый инструмент: «Текст вдоль границ»

- Выдели фигуру/векторный путь/рамку изображения, открой контекстное меню и выбери «Текст вдоль границ». На мобильном выбери соответствующий пункт ленты или меню «Ещё».
- Для маски выделения команда доступна в меню видов выделения. Если есть несколько контуров (включая отверстия), программа предлагает указать номер контура.
- Создаётся **один обычный текстовый слой** с режимом `textMode="boundary"`, атрибутами `pathBoundary`, а не набор растровых букв.
- Параметры: положение, сдвиг, сторона, обратное направление, отражение, отступ, выравнивание; оформление, шрифт и цвет изменяются стандартными средствами.
- Текст связан с исходной геометрией (`sourceId`) и хранит резервный контур (`fallback`). При удалении оригинала остаётся редактируемым.
- Старые документы с `textMode="path"` продолжают отображаться, но создание устаревшего режима из меню отключено.
- Все изменения продолжают использовать основной механизм Undo/Redo и JSON документа.

## Технические оговорки

- Геометрия векторных фигур разбирается через SVG Path. Для составных SVG пользователю предлагается выбрать один контур.
- Пиксельные границы выделения трассируются приблизительно с адаптивным шагом для больших масок; это может упрощать отдельные пиксели.
- Для текста длиннее замкнутого/открытого контура остаток строки хранится, но не отрисовывается; показывается предупреждение в настройках.
- Поддерживается линейное размещение глифов по касательной Canvas2D, а не полное типографское кернинг-формирование по траектории.
- Браузерный `file://` может использовать отдельное IndexedDB-хранилище. Перед обновлением экспортируй резервный JSON.
- PWA следует размещать на HTTPS либо localhost.

## Запуск

1. Однофайловый HTML — открытие непосредственно в браузере.
2. PWA — распаковать папку `kartochnaya` и разместить на локальном сервере/HTTPS.
3. Не переименовывать вложенные ресурсы `tool-icons/*.png`.
