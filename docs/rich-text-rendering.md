# Горизонтальный Rich Text (этап после PR #63)

Источник символов — только `element.text`. Модель `src/model/rich-text.mjs`
не изменена. `src/render/rich-text-layout.mjs` строит проекцию нормализованных
диапазонов и незаполненных промежутков, не изменяя данные.

## Реально отображаемые свойства

`fontFamily`, `fontWeight`/`bold`, `fontStyle`/`italic`, `fontSize`, `textColor`,
`letterSpacing`. В одном стиле явные `fontWeight` и `fontStyle` приоритетнее
булевых псевдонимов. Псевдоним диапазона при отсутствии его явного свойства
переопределяет начертание слоя: `bold:false` = 400, `italic:false` = normal.
Если у диапазона нет ни свойства, ни псевдонима, наследуется стиль слоя.
`bold:true` = 700. На слое действуют те же приоритеты.

`underline`, `strikethrough`, `baselineShift`, `fontFeatures`, variation settings
и прочие дополнительные свойства диапазонов сохраняются без визуализации.
Существующие подчёркивание/зачёркивание уровня слоя продолжают покрывать строку.

## Измерение, переносы и позиции

Движок владеет отдельным Canvas 2D context без transform. `measureText` использует
те же font, normal kerning и Canvas letterSpacing, что fillText/strokeText.
Слова собираются через границы стилей. Стиль сам по себе не создаёт перенос.
Пробельные последовательности сохраняются, включая концы строк. Явный LF создаёт
новую строку, в том числе пустую; CRLF трактуется как LF, отдельный CR игнорируется
для совместимости. Длинные слова и пробелы переносятся по графемам Intl.Segmenter.
Суррогатные пары, combining sequences и emoji ZWJ не разрезаются. Если диапазон
начинается внутри графемы, визуальный стиль всей графемы определяет первый символ;
сами диапазоны не переписываются.

Фрагменты строки имеют общую alphabetic baseline. Высота строки — максимум из
наибольшего fontSize × lineHeight и суммы максимальных ascent/descent шрифтов
этой строки. Таким образом, малый lineHeight не приводит к наложению смешанных
строк. Пустая строка использует базовый шрифт. Left/center/right применяются к
измеренной ширине каждой строки, top/middle/bottom — к высоте блока.

Canvas и PNG используют одну раскладку и один drawTextGlyphs. Поворот, flip,
прозрачность и эффекты остаются во внешнем рендерере. Сохраняется существующая
обрезка по рамке с припуском strokeWidth для обводки. Эффект textBackdrop строит
свои полосы по смешанным строкам. Тени и остальные эффекты получают реальную
растровую маску смешанных глифов.

При solid fill цвет диапазона используется с fillOpacity слоя. Для gradient и
image fill индивидуальные цвета диапазонов не применяются: вся смешанная
геометрия заполняет общую белую маску, затем действует прежний source-in.
Обводка сохраняет цвет, толщину, штриховку и прозрачность слоя.

## Кэш и загрузка шрифтов

Ключ раскладки включает текст, эффективные поддерживаемые стили, масштаб размеров,
ширину/высоту рамки, lineHeight, горизонтальное и вертикальное выравнивание.
Координаты слоя, zoom и DPR не входят в ключ. Максимум 128 раскладок и 4096
измерений; старейшие записи вытесняются. DOM/Range для Rich Text не используются.
loadingdone/loadingerror FontFaceSet и изменение числа зарегистрированных шрифтов
сбрасывают кэши. PNG заранее готовит шрифты всех реально отображаемых диапазонов,
включая унаследованные промежутки, с теми же правилами приоритета начертаний.

## Автоподбор и подгонка рамки

Существующий двоичный поиск 1…500 проверяет полную смешанную раскладку. Перед первым
авто- или ручным изменением базового размера слоя с абсолютными размерами диапазонов
запоминается `element.textRunsBaseFontSize`. Это единственное дополнительное поле:
опорный размер необходим, чтобы после сохранения/повторного открытия восстановить
пропорции, не меняя исходные `textRuns[].style.fontSize`.

Эффективный размер диапазона = сохранённый fontSize диапазона × текущий fontSize
слоя / textRunsBaseFontSize. Без опорного поля размеры диапазонов абсолютные;
унаследованный размер всегда равен текущему размеру слоя. Опорное поле создаётся
только при операции изменения размера, никогда при рисовании. `textRuns` остаются
неизменными. Подгонка рамки двойным кликом использует ширины и высоты тех же строк,
сохраняет привязку выравнивания и отключает автоподбор как раньше.

## Границы этапа

- Слои без непустых textRuns полностью сохраняют прежние переносы и отрисовку.
- Vertical, path, boundary и mobileArcRadius сохраняют прежнюю отрисовку и данные.
- Justify сохраняет прежнюю отрисовку базовым стилем; смешанные стили для этого
  выравнивания требуют отдельного этапа.
- Textarea остаётся в базовом стиле. Её переносы при редактировании смешанного
  текста могут отличаться от результата на холсте.
- Это механизм горизонтального текста слева направо: полноценный Unicode BiDi,
  переносы по языковым словарям, CSS tab stops и shaping через границы разных
  стилей не реализованы. Canvas трактует tab как обычный пробельный символ.
- При замене шрифта/размера внутри графемы действует стиль первого символа.
- При рамке меньше одной графемы или минимального размера 1px текст обрезается;
  бесконечного поиска размеров нет.

Проверки: `tests/rich-text-rendering.spec.js` наблюдает настоящие Canvas-вызовы,
проверяет пиксели Canvas/PNG, размеры/переносы/выравнивание/zoom, автоподбор,
повторное открытие, заливки/обводку/эффекты и длинный текст с 40 диапазонами.
`tests/rich-text-layout.test.mjs` проверяет приоритеты, безопасные границы,
масштабирование без мутаций и кэш. Старые text-layout/text-autofit/visual тесты
проверяют сохранение обычного текста; PNG-эталоны не обновляются.
