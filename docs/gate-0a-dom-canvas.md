## Остаточные X/Y и вертикальная геометрия (Gate 0B)

После `break-spaces`:

| Измерение | Chromium ΔX/ΔY, px | Firefox ΔX/ΔY, px |
| --- | ---: | ---: |
| Все графемы всей матрицы | 1.141/5.000 | 55.433/22.500 |
| Графемы только при совпавших строках | 1.141/5.000 | 1.150/4.500 |
| Collapsed caret всей матрицы | 1.141/5.000 | 55.433/25.500 |
| Collapsed caret только при совпавших строках | 1.141/5.000 | 12.700/25.500 |

В Firefox caret-выбросы при совпавших строках связаны с `before-LF` и `CRLF`:
в частности, collapsed Range около пустой строки может оставаться на предыдущей
визуальной строке. Сырые rect сохранены; нельзя представлять это как исправленную
caret-геометрию. Для soft-wrap сравнение учитывает обе позиции соседних графем
на одном offset, без добавления LF. Для hard breaks/пустых строк такой контракт
ещё требует отдельной работы.

Разбор вертикали:

- DOM line boxes не доступны напрямую через Range: Range даёт glyph/caret rect.
  В отчёте записаны computed line-height, исходные Range rect, оценённый baseline
  (Range top + Canvas font ascent), row probes и Canvas height/baseline.
  Это диагностическая оценка, не прямое чтение DOM baseline.
- При 20 px и line-height=1.15 CSS шаг строк =23 px; font ascent/descent=19/5 px.
  Canvas берёт max(23,24)=24 px. Для пяти строк длинного слова накопленная ΔY
  достигает 5 px в Chromium и 4.5 px в Firefox. Начальный top: −1 и −0.5 px.
- Unitless line-height наследуется пропорционально размеру span: 40×1.15=46 px.
  У mixed-size Canvas высота строки Chromium=46, Firefox=48 из-за font metrics;
  baseline первой строки 37/38. ΔY соответственно 0/3 px. Mixed-family и
  style-word дают до 4.609/4.100 px.
- Контроль line-height=1.5 даёт шаг 30 px для 20 px и 60 px для mixed-size;
  в обоих контролях ΔY=0. Это подтверждает влияние line box/font metrics,
  но не является предлагаемым изменением пользовательского line-height.
- Пустые строки Canvas используют базовые метрики: в `A\n\nБ\n` высоты
  24/24/46/24 (Chromium) и 24/24/48/24 (Firefox). DOM учитывает strut и соседние
  span; отдельные collapsed Range пустых строк в Chromium отсутствуют, в Firefox
  могут относиться к предыдущей строке. `rowProbes` сохраняет эти отсутствия.
  Нули Δ для полностью пустого текста/одних LF означают отсутствие glyph-пар,
  а не доказанную вертикальную точность. Существующее `missingCaretRects`
  относится только к парам графем, не ко всем пустым строкам.

Полный Gate 0 не пройден: допуск 2 CSS px превышен. Gate 0B должен определить
общий контракт baseline/line boxes, mixed-size и пустых строк, сохранить Canvas
экспортную геометрию и явно решить hard-break/empty-row caret-affinity. Произвольных
CSS-смещений, изменения Canvas или PNG ради совпадения нет. CR остаётся блокером
Gate 0A и не объявляется вертикальной задачей Gate 0B.

## Реальное нативное редактирование

Оба режима CSS проверяются полностью, 7 native-тестов на режим и браузер плюс
один matrix-тест на браузер: всего 30. Пройдены мышь/двойной клик, текстовый ввод,
ArrowRight/Left и Shift+Left, Up/Down и Shift+Down через soft wrap, Home/End,
Backspace/Delete на offset 8, выделение нескольких строк мышью, реальные Ctrl+C/V,
HTML paste как plaintext, Enter/повторные пустые строки, удаление emoji/ZWJ,
обратное выделение и round-trip всех UTF-16 offsets с двумя DOM affinities.
Клики при 50/100/200% и 0/30° также повторены в обоих режимах.

Для кандидата `break-spaces` оба реальных клика у конца первой/начала второй
строки дают `{anchor:8,focus:8}`. 8 ArrowRight →8; Down →15; Up →8 в обоих
браузерах. Shift+Down от 0 выделяет `[0,8)`, drag — `[4,12)`.
После Up → End Chromium получает 15, Firefox 8; последующий Home — 8 и 0.
Это различие визуальной affinity при одном offset, а не потеря логического текста;
результаты явно проверяются и записаны в `soft-wrap-native.json`.

Отдельно сохранён прежний сценарий Enter/Enter/Z → Home/Backspace → End:
текст `Привет мир\nZ`, Chromium offset 12, Firefox 10 в обоих CSS-режимах.
`native-end.json` и assertions фиксируют различие без программного исправления.

Copy/paste всего текста через soft wrap даёт точное удвоение исходной строки,
без LF. Backspace/Delete удаляют ровно ожидаемый символ. Matrix mount сохраняет
исходный текст побуквенно, включая CRLF/CR; Enter создаёт только ожидаемые LF.
Ухудшений в проверенных действиях не обнаружено. Это headless browser automation,
не проверка системной IME: composition guard остаётся синтетическим.
