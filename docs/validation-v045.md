## Пропущено из-за окружения — 1 проверка

Открытие самостоятельного HTML через file:// заблокировано управляемым Chromium:
`ERR_BLOCKED_BY_ADMINISTRATOR` (ENV-001). До проверки редактирования/PNG в этом
сценарии выполнение не дошло. Работоспособность file:// **не подтверждена**.

Реализованный тест нужно повторить там, где локальная навигация разрешена:

```sh
KARTOCHNAYA_REQUIRE_FILE_URL=1 npm run test:all
```

Этот строгий вариант в текущей среде не запускался: установленная политика
уже подтверждена диагностикой. Он предназначен для приёмочного прогона и не
превращает блокировку в skip.
