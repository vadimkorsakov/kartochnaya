## Независимый reproducer

Открыть `tests/experiments/text-stroke-dash-api.html` непосредственно в браузере. Он не использует код редактора и не обращается к сети. На одинаковых координатах рисуются текст и обычный прямоугольный path с solid, `[16,8]`, `[1,8]`/round. Семейство шрифта и текст можно изменить; размер 72 px, толщина 5 px, цвет #2266dd, фон белый. Под рисунками выводятся RGBA-сравнения и userAgent.

На Linux, Chromium 154 и Firefox 157, Arial:

| Canvas API | solid/dashed: пикселей >2 | solid/dotted | dashed/dotted | Максимум на канал |
|---|---:|---:|---:|---:|
| Chromium strokeText | 3824 | 6361 | 6559 | 221 |
| Firefox strokeText | 3836 | 6355 | 6554 | 221 |
| stroke path, оба браузера | 2164 | 4242 | 4322 | 221 |

Таким образом, в этих backend `strokeText()` применяет dash pattern. Новый движок контуров или SVG для этой диагностики не нужен.

## Цепочка редактора

Проверены код и фактические вызовы: существующий select → `styleInlineSelection()` → `textRuns` → `resolveRichTextStyle()` → layout → общий painter → `strokeText()`.

При выборе dashed у `AV` сохраняется `{start:0,end:2,style:{strokeStyle:'dashed'}}`; painter рисует именно `AV`, ширина 5, alpha 1, цвет #2266dd, `getLineDash()` возвращает `[20,10]`, cap butt. Dotted даёт соответствующий override, `[1,10]`, cap round. Другие диапазоны наследуют solid. Значение не теряется при native focus/selection lifecycle.

Проверка реальных пикселей исключает незаметную повторную сплошную отрисовку поверх пунктирной. Актуальность Preview подтверждается сохранением диапазонного override и получением соответствующего pattern в `strokeText()`.

## Семантический E2E

`tests/range-stroke.spec.js`: `stroke style semantic gaps and isolated neighbors via native select`, шрифты Arial и Stroke Serif (встроенная тестовая DejaVu Serif).

Текст `AV fi TEST`, 72 px, контур 5 px, fillOpacity 0, strokeOpacity 100. Выделяется только `AV`. Отдельные измерения выполняются для WYSIWYG, Canvas после выхода и экспортированного PNG; обычная pixel parity сохранена для каждого стиля.

Критерий:

- Все три пары должны различаться более чем на `max(64, ceil(5% непрозрачного solid-контура))` пикселей, каждый с разницей RGBA >32.
- Dashed и dotted должны превратить не менее того же порога пикселей непрозрачного синего ядра solid в почти белый фон (RGB >245).
- Dotted должен иметь минимум на 5 независимых компонентов больше, чем solid; компоненты менее 3 пикселей исключены.
- Вне области выбранного `AV` нет пикселей с изменением >2.

Порог исключает несколько пикселей сглаживания, а белые отверстия и компоненты проверяют фактическое изображение контура. Простого сохранения JSON, вызова setLineDash или совпадения двух одинаково ошибочных рендеров для прохождения недостаточно.

| Движок / шрифт | solid/dashed >32 | solid/dotted >32 | dashed/dotted >32 | Белых разрывов dashed / dotted | Компонентов solid / dotted |
|---|---:|---:|---:|---:|---:|
| stroke-chromium / Serif | 953 | 1813 | 1781 | 627 / 1010 | 2 / 36 |
| stroke-chromium / Arial | 873 | 1658 | 1600 | 621 / 943 | 2 / 41 |
| stroke-firefox / Serif | 955 | 1822 | 1787 | 624 / 1008 | 2 / 37 |
| stroke-firefox / Arial | 878 | 1649 | 1597 | 619 / 933 | 2 / 41 |

В каждой строке метрики одинаковы для live WYSIWYG, Canvas и PNG. Изменённых пикселей >2 у соседних фрагментов — 0. Все четыре E2E прошли на реальном Preview. Новые E2E проходят на исходной реализации в проверенном окружении; утверждать red-before/green-after для сообщённого дефекта сейчас нельзя.

## Окружение и ограничения

Firefox запускается разрешённым способом вне sandbox (в sandbox он не видит временный профиль). Для HTTPS Preview предоставленный средой CA импортируется только во временный NSS-профиль. Проверка TLS включена; proxy environment, настройки системы, GPU и аппаратное ускорение не менялись. Проверка на пользовательской ОС/ускорителе пока отсутствует.

Merge и production deploy не выполняются. Зелёные результаты этой диагностики не снимают пользовательский блокер.


Повторные финальные проверки: 604/604 unit (включают модель, layout, painter), 17/17 source, build, build:verify, git diff --check — успешно. Полная матрица Playwright не перезапускалась.

## Слой, созданный с нуля через интерфейс

Дополнительно в обоих браузерах пройден путь без импорта fixtures: новый документ 320×240 → desktop «Текст» → рамка 280×190 → размер 72 через инспектор → ввод AV fi TEST → выделение всего текста → fillOpacity 0, strokeWidth 5, цвет #2266dd через штатные поля/поповеры → выделение AV → native solid/dashed/dotted. Для каждого выбора проверены WYSIWYG, Canvas после закрытия и экспорт PNG.

Обе проверки прошли. Числа пикселей >32 для трёх пар совпадают с Arial в таблице выше: Chromium 873/1658/1600, Firefox 878/1649/1597. Соседи не меняются выше допуска 2. Дефект не воспроизводится и при создании слоя без импортированного документа.

HTML reproducer отдельно открыт и проверен в обоих браузерах через localhost. Если политика браузера блокирует file:// (ENV-001 управляемой среды), запустить из корня репозитория `python3 -m http.server 4322 --directory tests/experiments` и открыть http://localhost:4322/text-stroke-dash-api.html. Системные ограничения для этого не отключаются.
