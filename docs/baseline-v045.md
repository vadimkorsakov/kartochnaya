# Исходное состояние КАРТОЧНОЙ v0.45

Этот документ относится только к этапу 0: фиксации существующего поведения.
Сборка, рефакторинг, исправления редактора и изменение форматов в этот этап не входят.

## Базовая точка

- Коммит: `7623091139c2b8997067fd51de388918d64566cb` (`Add files via upload`).
- Каталог релиза: `kartochnaya v0.45/`.
- Контрольный манифест: [baseline-v045.json](baseline-v045.json).
- SHA-256 `index.html`: `7d2c286b31ba8e2aa797177e8c7ab359bcbda816fc06bf2f1226dc5b1baec27a`.
- Размер HTML: 1 039 010 байт, 5070 символов перевода строки, два блока style,
  один блок script. Статического подключения manifest нет.
- В контрольном манифесте перечислены все 19 файлов релиза, их размеры и SHA-256.
  Проверяются как содержимое, так и полный список файлов.

Файлы релиза, включая его README, оставлены неизменными. Тестовая инфраструктура
располагается рядом с релизом и не подключается из него. Новый корневой package.json
не превращает редактор в npm-приложение: зависимости нужны только тестам.

Манифест сформирован из чистого checkout базового коммита. При следующих этапах
нельзя пересоздавать его из изменённого приложения для получения зелёного теста.
Сначала следует отдельно согласовать изменение проверяемого артефакта и сравнение
с базовой версией; исходную контрольную точку нужно сохранить.

## Что именно зафиксировано тестами

- Создание пустого документа 320×240 через UI.
- Создание и повторное редактирование текстового слоя.
- Прямоугольник из встроенного каталога (`basic0`).
- Загрузка синтетического четырёхцветного PNG через инструмент фото.
- Undo/Redo одного добавления с сохранением идентичности слоя.
- Подтверждение записи через чтение IndexedDB и открытие документа после reload.
- Декодирование PNG, CRC, размеры, непрозрачные пиксели и контрольный цвет фигуры.
- Доступность 18 ресурсов поставки, кроме README, с проверкой исходных байтов.
- Офлайн-загрузка через активированный service worker и редактирование/экспорт офлайн.
- Три PNG-эталона: пустой холст, фигуры, текст с фиксированным шрифтом.
- Два отдельных expected-failure теста импорта.

Тест `file://` реализован, но в текущем облачном Chromium не прошёл навигацию:
администраторская URL-политика возвращает `ERR_BLOCKED_BY_ADMINISTRATOR`.
Это ограничение окружения, не установленный дефект редактора. Оно не заменяется
HTTP-проверкой. См. [инструкции и строгий режим](../tests/README.md).

## Границы защиты

Это начальная защита для небольших переносов кода, а не подтверждение всех
возможностей редактора. Эффекты, сложные маски, группы, серии, мобильная клавиатура,
производительность и обновление PWA между версиями не покрыты базовым набором.
Восстановление проверено после reload в том же browser context, а не после
перезапуска ОС или завершения процесса браузера.

Текущие [известные дефекты и риски](known-issues.md) сохраняются. Их исправления
потребуют отдельного задания и отдельных изменений тестовых ожиданий.
