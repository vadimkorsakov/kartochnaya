## Анализ зависимостей

| Функция | Зависимости | Повторные объявления | Решение |
| --- | --- | --- | --- |
| `html(s)` | `String`, `replace`, локальный callback и таблица сущностей | Нет | Извлечена буквально |
| `clamp(x,a,b)` | `Math.min`, `Math.max` | Нет | Извлечена буквально |
| `fmt(n)` | `Number`, `Math.round` | Нет | Извлечена буквально |

Это три `const` со стрелочными функциями. Они не читают `app`, DOM,
браузерные API или другие функции редактора. До них расположены только
объявления `$`, `$$`, `uid`, `clone`, которые не вызывают эти примитивы при
инициализации. Место и порядок инициализации, лексическая область IIFE,
имена, параметры и тела сохранены. Фрагмент содержит только исходные три строки.

Общий `app` связывает документ, слои/группы, историю, инструменты, Canvas,
шрифты, мобильное состояние и IndexedDB; разделять его сейчас небезопасно.
У `fitCanvas`, `applyZoom`, `renderSlideStrip`, `changeSlide` по два объявления:
поздние версии обслуживают в том числе рабочее пространство серий.
Они оставлены буквально в прежнем порядке.

`drawTextGlyphs` имеет исходное объявление и две последовательные обёртки;
`paintText`, `paintDocument`, `openInlineText`, `positionInlineText`,
`refreshInspector`, `setSelected` — исходное объявление и последующее
присваивание функции. Сохранение ссылок на прежнюю реализацию и порядок
установки, особенно для boundary-текста, остаются частью контракта.

Изучены два обработчика Undo/Redo: capture-обработчик должен остановить
событие перед более ранним общим обработчиком. Также сохранены приоритетный
capture Enter/Escape для обрезки, переключение инструментов, pointer/touch-router,
pointercancel и контекстное меню с capture-действием создания boundary-текста.
Ни один из этих участков не редактировался.

## Четыре браузерных контракта

Новый `tests/core-contracts.spec.js` использует интерфейс, штатные JSON/PNG-экспорты,
чтение общедоступного Canvas и IndexedDB только для наблюдения сохранения.
Каждый тест получает новый контекст браузера и создаёт синтетические документы.
Внутренний `app` не раскрывается; production-hooks отсутствуют.

1. Создание и изменение многострочного текста. При 100% масштабе и снятом
   выделении декодированные пиксели Canvas точно равны PNG-экспорту до и после
   изменения; изменение текста обязано изменить пиксели и JSON.
2. Три слоя, перестановка мышью, порядок DOM и JSON, один шаг клавиатурного
   Undo/Redo, последовательные Undo и оба варианта Redo. Проверяются конкретные
   идентификаторы и содержимое, поэтому двойное выполнение команды обнаруживается.
   Проверяется сохранение и повторное открытие. При перестановке существующий
   редактор добавляет перемещённому слою `groupId: null`; это учтено явно.
3. Два документа с разным содержимым: повторные переключения сохраняют активный
   идентификатор, выделение и масштаб. Undo в первом не затрагивает второй;
   Redo первого восстанавливает именно его объект.
4. Текст вдоль границы создаётся через контекстное меню фигуры, без импорта
   с известным KF-001. Проверяются `sourceId`, совместное смещение фигуры и текста,
   изменение PNG от движения и от скрытия только текста, сохранение ссылки и
   точное равенство экспортируемых пикселей после повторного открытия.

Полные мобильные жесты, все режимы текста, группы, обрезка и многослайдовые серии
новыми сценариями не покрыты. Проверка вкладок выбрана вместо дополнительной
проверки слайдов, чтобы сохранить небольшой объём этапа. Новые тесты не исправляют
и не маскируют старые ошибки.

## Сборка и защита исходников

`src/core/primitives.js` — исходный фрагмент, пока не ES-модуль.
В `src/editor.js` вместо трёх строк стоит единственный маркер
`/*{{KARTOCHNAYA:CORE_PRIMITIVES_JS}}*/` с переводом строки LF.
`scripts/compile-html.mjs` читает Buffer, заменяет весь маркер вместе с LF
на исходные байты фрагмента, затем помещает восстановленный JavaScript
в прежний script-тег HTML. Добавочных байтов и внешних runtime-зависимостей нет.
Оба дистрибутива получают один восстановленный HTML; ZIP-упаковщик не менялся.

Пропуск или дублирование JS-маркера, его некорректная форма, неизвестные или
незавершённые маркеры в основном JS, нерешённые маркеры во фрагменте и отсутствие
файла приводят к ошибке. Возврата к историческому HTML нет.

`test:source` теперь содержит пять контрактов. Проверяются все исходные байты
JavaScript и HTML, буквальный фрагмент и единственные объявления в прежнем
порядке, ошибки сборки, две полные сборки и отдельные цели. Во временной копии
поочерёдно меняется каждый из пяти входов `src/`, включая новый фрагмент:
HTML и ZIP обязаны измениться, HTML внутри ZIP обязан совпасть с собранным HTML.
Удаление основного JS или фрагмента обязано остановить сборку.
Постоянные исходники, ожидаемые SHA и PNG при этих пробах не редактируются.

Существующие npm-команды сохранены. Единственный workflow **Build HTML and PWA**
не требует изменения: он уже отслеживает `src/**` и запускает обновлённый
`test:source`, сборку, `build:verify`, публикацию скачиваемых артефактов.
Деплой и Merge не выполняются.
