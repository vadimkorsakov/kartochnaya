## Метод

Существующий matrix-тест сравнивает 24 исходных сценария в двух вариантах:
`original` — прежний `break-spaces`, unitless line-height; `font-metrics` — тот же
DOM и `break-spaces`, но host и каждый span получают CSS line-height в px:
`max(fontSize * lineHeight, fontBoundingBoxAscent + fontBoundingBoxDescent)`.
Метрики измеряются через `measureText('Mg')` с соответствующим family/weight/style/size.
Если font bounding metrics отсутствуют, диагностика падает; fallback и произвольных
пиксельных поправок нет. Применённые и computed значения сохраняются в JSON.

Canvas engine используется без изменений; для каждого сценария assertions
проверяют точное равенство всех Canvas rows/fragments/координат между вариантами,
исходный текст и отсутствие непарных графем. UTF-16 интервалы, CRLF длиной 2,
`nextStart` и `softWrap` сравниваются как раньше. ΔY означает Range top против
Canvas baseline минус ascent, а не прямое чтение baseline или line box из DOM.

Добавлены `caretRowProbes`: начало **каждой Canvas-строки**, включая пустую и
последнюю, измеряется collapsed Range с upstream и downstream DOM points.
Обе affinity сохраняются независимо, включая отсутствие rect и ошибочную строку.
Старые `rowProbes`, glyph-pair caret и JSON-поля остаются. Soft-wrap glyph caret
по-прежнему сравнивается с обеими соседними Canvas-позициями одного offset;
hard/empty row probes сравниваются с ожидаемой строкой без подстановки соседей.

## Остаточные расхождения и ограничения

- Mixed-size: ΔY `mixed-size` 0 → 0 (Chromium), 3 → 0 (Firefox);
  `style-word` и `mixed-family` 4.609 → 0 / 4.100 → 0. Контроли line-height=1.5
  сохраняют ΔY=0. Для 20 px CSS высота кандидата 24 px в обоих браузерах;
  для 40 px — 46 px Chromium и 48 px Firefox. Остаточная ΔX не меняется:
  `style-word` до 1.141/1.150 px, `mixed-size` до 0.553/0.550 px.
- LF/CRLF: логические строки, исходный текст и UTF-16 интервалы сохранены;
  glyph ΔY в `before-LF`, `blank-lines`, `CRLF` стала 0. Это не исправляет
  collapsed caret: в Firefox `before-LF` сохраняет ΔX=12.700 и ΔY=24;
  `CRLF` сохраняет ΔY=24. Native Selection не корректируется программно.
- Девять пустых строк × две DOM affinities = 18 probes в каждом варианте/браузере:
  `before-LF` (1), `blank-lines` (2), `empty` (1), `only-LF` (3), `CRLF` (2).
  Chromium не даёт ни одного rect. Firefox даёт все 18, но 14 вне допуска.
  В Firefox candidate `before-LF` trailing offset 19: ΔX/ΔY=64.150/24;
  `CRLF` offsets 7 и 15: 55.433/24 и 45.100/24;
  `blank-lines` offsets 2 и 5: 13.683/24 и 27.433/29.
  Обе DOM affinity в этих случаях дают одинаковые неверные rect.
  `only-LF` offsets 1 и 2 остаются на предыдущей строке (ΔY=24), offset 0 точен.
  У полностью пустого текста Firefox rect точен, Chromium rect отсутствует.
- Поэтому max ΔY=0 у графем не означает совпадения высот/положений всех пустых
  line boxes. Доступность и affinity пустых строк остаются блокерами.
- Одиночный CR Firefox: строки по-прежнему различаются, max glyph ΔX/ΔY
  55.433/22.500 → 55.433/24.000. Во всей матрице Firefox, включая этот блокер,
  max glyph ΔX/ΔY 55.433/22.500 → 55.433/24.000;
  max glyph caret 55.433/25.500 → 55.433/24.000. Семантика CR не менялась.
